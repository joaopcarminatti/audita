# HU-002 — Emitir certificado de conclusão

**ID:** HU-002
**Épico:** Certificação
**Responsável:** Gustavo Nery
**Prioridade:** Média
**Estimativa:** 8
**Requisito:** RF-021
**Dependências:** HU-001

## Narrativa
Como aluno concluinte,
Quero emitir o certificado do curso em PDF,
Para que eu possa comprovar a conclusão junto ao meu empregador.

## Critérios de aceitação
- Dado que o aluno concluiu 100% das aulas e obteve média igual ou superior a 7, Quando solicita o certificado, Então o PDF é gerado com nome, curso, carga horária e código de validação.
- Dado que o aluno não atingiu a média mínima, Quando solicita o certificado, Então o sistema informa os requisitos pendentes.
- Dado que o certificado já foi emitido, Quando o aluno solicita novamente, Então o sistema reemite o mesmo código de validação.

## Regras de negócio
- RN-01 O código de validação é único e verificável na página pública de validação.
- RN-02 O certificado é invalidado apenas se a matrícula for cancelada por fraude.
